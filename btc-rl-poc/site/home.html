The Desk — six traders: five rules and one that learns TA spec · simulated · not advice

Each starts with $1,000 and pays real asks and fees. 🦊 Dartmon, the Follower places the current best bidder's call (the arm leading its last 10 settled decisions), risking at most 10% of funds. 🐢 Rungmon, the Ladder mirrors every trade uncapped and banks $1k at $11k, then ×10. 🦉 Sagemon, the Disciplined takes any desk entry only at ≥77% confidence. 🐉 Blazemon, the Gambler stakes 33% of his capital on every entry (about 1.6× Kelly at these asks), capped by the LIVE near-touch depth of the book — the aggressive end of the sizing curriculum. 🐿️ Stashmon, the Saver starts with $10k, stakes 25%, and banks 25% of every win as savings that never return to play. 🤖 Metamon, the MLE is the one that learns — a supervised model that watches the five rule-traders' signals, predicts the odds of each bet winning, and only bets (half-Kelly sized) when the expected value is positive; it retrains on every outcome. Reviewed at end of day. Nothing is ever purchased.

Live exchange integration — Kalshi sandbox demo API · fake funds · not advice

Our decisions are re-submitted as real, cryptographically-signed orders to Kalshi's demo trading engine (fake balance, verified demo-only key — authenticates on the sandbox, rejected by production). Execution is proven: standard contracts return HTTP 201 accepted and rest live in the exchange book (the KXHIGHNY row is a live resting order in the account). The 15-minute crypto contracts return 404 because Kalshi's demo doesn't route crypto through its public order API — a venue quirk, not our signing. Zero real money; each row is an actual signed request and the exchange's response.
